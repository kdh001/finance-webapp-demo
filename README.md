# MyFinance Local — 합성 데이터 데모

은행·카드 CSV를 읽어 소비를 분류하고 수입·지출 추이, 재무 지표와 목표를 보여 주는 로컬 웹앱의 데모입니다. 포함된 거래·계좌·프로필은 이 공개 후보를 위해 새로 만든 **합성 데이터**입니다.

## 실행

Node.js 24와 npm이 필요합니다. 프로젝트 폴더에서:

```bash
npm ci
npm run dev
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 개발 서버는 로컬 주소에서만 수신합니다. 5173 포트가 이미 사용 중이면 중단하므로 포트를 비운 뒤 다시 실행하세요. 서버 기본 포트는 3001이며, `PORT` 환경 변수로 바꾸면 개발 프록시에도 적용됩니다. 의존성 설치에는 npm 레지스트리 접속이 필요합니다.

```bash
npm test       # 분류 및 합성 CSV 집계 테스트
npm run build  # 클라이언트 타입 검사와 빌드
```

## 기능과 범위

- 합성 거래에 대한 월별 수입·지출과 카테고리별 현황
- CSV 업로드·컬럼 매핑·분류 변경, 재무 지표와 목표 화면
- 파일당 최대 1 MiB, 헤더 외 10,000행과 100열, 한 행 16,384자, 저장 50개까지 허용합니다. 파일명은 무작위로 바꿔 저장하며 매핑 대기는 최대 8개·5분입니다.
- 실시간 계좌 연동이나 자동 거래는 제공하지 않습니다.

이 사본에서는 원본의 **Anthropic API 연결, AI 어드바이저·대화, API 사용량 집계, 엑셀 변환 스크립트**를 제외했습니다. 재무 데이터를 외부 AI에 전송하는 기능은 없습니다. 브라우저와 서버는 같은 컴퓨터에서 통신하며 설정·업로드한 파일은 로컬 `data/`에 저장될 수 있습니다. 이 데모는 인증·다중 사용자·공개 배포를 위한 보안 검증을 거치지 않았으므로 실제 금융정보를 입력하지 마세요. 수치와 분석은 예시이며 금융 조언이 아닙니다.

## 제작 과정

원본의 React 화면과 CSV 처리·집계 코드를 발췌해 수정했습니다. 합성 데이터·테스트와 업로드 제한 및 로컬 접근 제한은 이 사본을 정리하면서 새로 작성했습니다. 원본 프로젝트는 AI의 도움을 받아 제작했습니다. 저장된 구현 메타프롬프트에는 Claude Code를 이용한 구현 요청이 있습니다. 사용자의 구체적인 기여와 각 부분의 작성자는 확인되지 않았으므로 여기서 단정하지 않습니다. 이 공개 후보는 원본에서 일부 기능을 제외하고 합성 자료와 테스트를 추가해 정리한 것입니다.
